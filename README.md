Kalkulator analogowy z uzyciem Arduino.
-------------------
Wartosci odpowiadajace napieciu na odpowiednim pinie INPUT sa zamieniane na wartosc liczbowa przez program w Arduino.
Dane sa przekazywane przez Serial do odpowiedniego urzadeznia
gui.py analizuje i prezentuje dane w graficzny sposob, aby kalkulator mogl byc urzyty w przystepny sposob
